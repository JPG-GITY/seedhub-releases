The Windows installer is not code signed yet. If SmartScreen says "Windows protected your PC",

# Seed HUB (español)

Instaladores de Seed HUB, de BytePlus. Este repositorio solo tiene las versiones publicadas; no tiene código.

Descarga la última versión desde [Releases](https://github.com/JPG-GITY/seedhub-releases/releases/latest).
Una vez instalada, Seed HUB revisa esta página al abrirse y ofrece actualizarse sola.

En Windows, si SmartScreen dice "Windows protegió tu PC", elige **Más información → Ejecutar de todas formas**.
